Authentification

Crée une clé dans ton espace (POST /api/keys depuis l'application, ou bientôt depuis Paramètres → API). La clé, au format rb_live_…, n'est affichée qu'une seule fois : seule son empreinte SHA-256 est conservée. Envoie-la dans l'en-tête Authorization :

curl https://relbrain.ai/api/v1/quizzes \
  -H "Authorization: Bearer rb_live_xxxxxxxxxxxxxxxxxxxx"

Chaque clé a des permissions (read, write) et peut être révoquée à tout moment. Maximum 5 clés actives par compte.

Générer un quiz depuis un texte scope write

POST /api/v1/quizzes
Content-Type: application/json

{
  "text": "La photosynthèse est le processus par lequel…",   // 100 à 200 000 caractères
  "count": 10,                 // 1 à 50, selon ton forfait
  "type": "qcm",               // qcm · vf · court · calcul · texte · mixte
  "difficulty": "moyen",       // facile · moyen · difficile · expert
  "title": "SVT — Photosynthèse"
}

La génération consomme une requête IA de ton quota quotidien et un quiz de ton quota mensuel.

Erreurs et limites

Toutes les erreurs suivent le même format :

{ "error": { "code": "rate_limited", "message": "Limite de 60 requêtes par minute atteinte." } }
HTTPCodeSignification

402quota_exceededLimite du forfait atteinte
403insufficient_scopeLa clé n'a pas la permission requise
429rate_limitedPlus de 60 requêtes par minute pour cette clé
502/503ai_unavailableService d'IA momentanément indisponible : réessaie avec un délai croissant

Webhooks bientôt

L'architecture est prête côté serveur ; l'abonnement aux webhooks ouvrira prochainement. Événements prévus, envoyés en POST JSON signé (en-tête RelBrain-Signature, HMAC-SHA256) :

  • document.ready — un document a fini d'être analysé ;
  • quiz.completed — un quiz a été terminé (score, durée) ;
  • achievement.unlocked — un badge a été débloqué.

Widgets embarquables bientôt

Pour les enseignants et les blogs éducatifs : intégrer un quiz RelBrain dans une page web en une ligne.

<iframe src="https://relbrain.ai/embed/quiz/QUIZ_ID"
        width="100%" height="520" loading="lazy"
        title="Quiz RelBrain"></iframe>

SDK JavaScript en préparation

Un client officiel (@relbrain/sdk) encapsulera l'authentification, la pagination et les nouvelles tentatives automatiques. En attendant, l'API REST s'utilise avec n'importe quel client HTTP :

const res = await fetch('https://relbrain.ai/api/v1/quizzes', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.RELBRAIN_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ text: cours, count: 10, type: 'qcm', difficulty: 'moyen' }),
});
const { data: quiz } = await res.json();
Ne mets jamais ta clé API dans du code exécuté par un navigateur ou une application mobile publiée : appelle l'API depuis ton serveur.
